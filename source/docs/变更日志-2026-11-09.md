## 四、接口清单

成员侧写操作校验 `club-csrf-v1` 令牌与同源；管理侧复用 `manage-csrf-v1`。

| 方法 | 路径 | 鉴权 | 说明 |
|---|---|---|---|
| GET | `/api/club/profile` | MUA | 模板、信誉、活动记录、游玩统计、CSRF 令牌 |
| PUT | `/api/club/profile` | MUA + CSRF | 保存模板；已有模板必须带邮箱验证码 |
| POST | `/api/club/profile/email-code` | MUA + CSRF | 向登记邮箱发送 6 位验证码，3 次/5 分钟 |
| POST | `/api/club/profile/mc-bind` | MUA + CSRF | MUA 密码经 Yggdrasil 验证角色归属，只存 UUID |
| GET | `/api/club/events` | 可选 MUA | 已发布活动列表，含我的报名状态 |
| GET | `/api/club/events/<id>` | 可选 MUA | 活动详情、表头、完整信息模板、黑名单状态 |
| POST | `/api/club/events/<id>/signup` | MUA + CSRF | 报名；模板字段由后端填充，仅提交 `custom` |
| POST | `/api/club/checkin` | 签到码 | 预留接口，参数 `eventId`、`studentNo`、`code`；限频 30 次/分钟 |
| GET | `/api/manage/club/events` | 管理员 | 活动列表，含签到码与报名/签到人数 |
| POST | `/api/manage/club/events` | 管理员 + CSRF | 新建活动与表头 |
| GET | `/api/manage/club/events/<id>` | 管理员 | 活动详情 |
| PUT | `/api/manage/club/events/<id>` | 管理员 + CSRF | 修改活动与表头 |
| DELETE | `/api/manage/club/events/<id>` | 管理员 + CSRF | 删除活动；报名中/待结算的活动不可删除 |
| GET | `/api/manage/club/events/<id>/records` | 管理员 | 报名名单分页（30/页）与姓名/学号搜索 |
| PUT | `/api/manage/club/events/<id>/records/<recordId>` | 管理员 + CSRF | `{"checkedIn": true/false}` 手动签到 |
| POST | `/api/manage/club/events/<id>/settle` | 管理员 + CSRF | 结算未签到，累计 3 次写黑名单 |
| GET | `/api/manage/club/events/<id>/export.xlsx` | 管理员 | 导出 xlsx，行头 + 列头按配置顺序 |

## 八、补充：报名人数上限（同日追加）

- `events` 新增 `capacity INTEGER NOT NULL DEFAULT 0`，0 表示不限；服务启动时对已有库执行 `ALTER TABLE` 迁移，已确认测试站与正式站均生效。
- 管理端活动表单新增「报名人数上限」输入，列表显示「报名 / 签到 / 上限」。
- 报名在 `BEGIN IMMEDIATE` 事务内统计已报名人数，满员返回 409「报名人数已满」；前台卡片与详情显示「已报名 N / 上限 M」，满员时隐藏报名按钮并提示。
- 验证：`capacity=1` 时第二人报名被 409 拦截；提高到 2 后报名成功（`signupCount=2`）。正式站 `PRAGMA table_info(events)` 含 `capacity`，创建 `capacity=3` 活动 201、删除 200。
- 更正：下方「已知限制」中「活动未做报名人数上限」已过时，请以上述补充为准。

### 10.3 启动器协议唤起

- 注册 `HKCU\Software\Classes\njitmcl`，命令行 `"<exe>" "%1"`，无需管理员权限。
- 单实例：命名管道 `NJITMCL_Protocol` 把参数转给主实例；启动器未运行时先暂存 `PendingProtocol`，初始化后处理。
- 流程：协议触发 → 刷新微软登录 → `POST /api/account/launcher-login` → 浏览器打开 `<站点>/#mc-login?code=…` → 前端兑换并 `history.replaceState` 清除 code。
- 窗口底部进度条：4px、`#1377DB`、从左侧增长、贴内容框底边；成功绿色提示、失败红色提示。

### 10.4 双 MC 角色

- 旧 `profiles.mc_uuid` 自动迁移为 `player_links(mua)`。
- 个人中心同时展示「MUA 角色」与「正版角色」；游玩时长按两个 UUID 合并统计。
