## 二、启动器改动

| 文件 | 类型 | 说明 |
|---|---|---|
| `Modules/ModGithubIp.vb` | 新增 | 候选采集（内置种子 + 阿里/腾讯 DoH + 死段黑名单）、12 并发 TCP+TLS+首字节探测、6 小时缓存、失败 IP 拉黑 10 分钟 |
| `Modules/Base/ModGithubProxy.vb` | 新增 | 本地 CONNECT 代理（随机端口、5 域名白名单、裸 TCP 透传、120 秒空闲超时）；`IWebProxy` 仅对 GitHub 域名生效，其余委托系统代理 |
| `Modules/Base/ModNet.vb` | 修改 | `RequestClient` 与 `ThreadClient` 的 `HttpClientHandler` 注入代理 |
| `Modules/ModSiteAuth.vb` | 修改 | `HandleProtocol` 新增 `njitmcl://download` 分支：协议/端口/域名/路径白名单校验、`LoaderDownload` 原生下载、SHA256 校验、保存后定位文件 |
| `Application.xaml.vb` | 修改 | 启动时拉起优选代理 |
| `Pages/PageSetup/Settings.vb` | 修改 | 新增 `NjitGithubIpEnabled`（默认开）与 `NjitGithubDownloadFolder` |
| `Pages/PageSetup/PageSetupSystem.xaml(.vb)` | 修改 | 设置 → 系统 → 下载：新增「GitHub 下载目录」文本框与「浏览」按钮 |
| `Modules/Base/ModBase.vb` | 修改 | 版本 `1.7.0`，正式 `452` / 快照 `453` |

**技术要点**：.NET Framework 4.8.1 无法自定义 DNS，采用「本地 CONNECT 代理 + `IWebProxy` 白名单」；TLS 端到端、SNI 为真实域名、证书链与主机名校验保持严格，未新增任何证书例外。

**安全约束**：协议只接受 `https`、443、`github.com` / `objects.githubusercontent.com` / `release-assets.githubusercontent.com`，`github.com` 路径必须匹配 `/owner/repo/releases/download/`；拒绝 `..`、超 2048 字符的 URL。

## 七、已知限制

- 官网三处改动基于本地 `website-src` 副本，**尚未部署到公网/测试站**；服务器 `/opt/blockdimension` 为运行权威，部署前需逐行对比。
- 首次 GitHub 请求会同步执行一次 IP 优选，约 2–3 秒；同一域名后续 6 小时复用缓存。
- 未做 `raw.githubusercontent.com` 优选（实测 93% `tls_reset`，稳定阻断）。
- 协议下载未校验登录态（资源本身公开）。
