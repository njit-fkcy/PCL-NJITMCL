## 三、本次概括

- **改了什么**：新增 GitHub 源码仓库 `njit-fkcy/PCL-NJITMCL-Source`（以 1.5.6 为起点、`MeloongCore` 内联、不含上游历史与上游 CI）；新增内网源码镜像 `_launcher/_source/v<版本>/`；发布流程由九步改为十步，源码同步固定为第 5 步。
- **影响范围**：仅社团维护者。玩家客户端、更新清单、官网下载页、Release 资产均未改动，`versionCode` 不变。
- **回滚方式**：删除 GitHub 仓库 `PCL-NJITMCL-Source` 与内网 `_launcher/_source/v1.5.6/`；把规则与档案的发布流程改回九步。
