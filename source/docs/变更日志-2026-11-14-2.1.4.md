# 变更日志 · 2.1.4（2026-11-14）

只改更新推送：从「强制 / 可选」两态换成三档。

## 更新档位

更新清单新增 `level` 字段，取值 `normal` / `urgent` / `incompatible`。

| level | 弹窗标题 | 能否跳过 |
|---|---|---|
| `normal` | 发现更新 | 可（立即更新 / 稍后） |
| `urgent` | 紧急更新 | 不可，只有「开始更新」 |
| `incompatible` | 不兼容更新 | 不可，只有「开始更新」 |

- 紧急更新提示「本次为紧急更新，包含需要立即生效的修复」；不兼容更新提示「当前版本与服务端接口不兼容，继续使用会出现联机与更新异常」
- 两档强制级别不受「自动检查更新」开关影响：关掉自动检查的用户同样会收到
- 下载完成后的处理不变：强制档直接重启替换，普通档询问是否立即重启

## 兼容

清单同时保留原有的 `force` 布尔字段：

- 新版客户端优先读 `level`，读不到时按 `force` 折算（`true` → `urgent`，`false` → `normal`）
- 只认 `force` 的老客户端（≤2.1.3）仍按原逻辑工作：`urgent` 与 `incompatible` 都写 `force: true`

## 打包

`build.ps1` 新增 `-UpdateLevel normal|urgent|incompatible`，默认 `urgent`；构建结束会打印本次档位。

## 说明

本版不含联机进服校验（正版 / 双验证）与 `njit-online-agent`，那部分留给 2.2.0。
